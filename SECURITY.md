# Security Policy

The project's [security policy](.github/SECURITY.md) describes supported versions,
reporting guidelines, safe testing, and security controls.

## Reporting a Vulnerability

Please report vulnerabilities through GitHub's
[private vulnerability reporting](https://github.com/fatmakahveci/Django-Todo-App/security/advisories/new).
Do not publish vulnerability details in public issues, discussions, or pull requests.

If private reporting is unavailable, follow the alternative contact instructions
in the [security policy](.github/SECURITY.md#reporting-a-vulnerability).

Include the affected version or commit, impact, and reproduction steps using test
data. Remove passwords, secret keys, session cookies, and personal information.
